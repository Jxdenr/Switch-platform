Import prefixes

CSV with columns country, network, mcc, mnc, prefix. Several prefixes in one row can be separated by spaces. Existing prefixes are moved to the network in the file.

Prefixes give the network a number was first issued to. Where numbers can be ported (UK and most of Europe) some will have moved network; an HLR/number portability lookup is needed for those to be exact.
